# API Architecture

## Style

The backend provides a REST API implemented with Flask. It is the boundary between the React frontend and application services.

## Request Path

```text
React feature UI
  ↓
Dedicated frontend API/service layer
  ↓
Flask REST API and Pydantic DTO validation
  ↓
Application services
```

## Responsibilities

- Receive and return HTTP representations.
- Validate DTOs with Pydantic.
- Delegate use cases to application services.
- Return data needed by consultation, messaging, recommendations, summaries, and appointment-booking features.

## Constraints

Routes must not contain direct persistence manipulation, domain business logic, or LangChain/provider-specific logic. Appointment requests are handled through deterministic application behavior rather than autonomous LLM actions.
